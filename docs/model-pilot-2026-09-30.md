# Первое сравнение GPT‑6.1 Sol High и XHigh

2026-09-30 выполнены шесть реальных запусков Codex CLI через подписочный вход ChatGPT: три учебные задачи × два effort. Все шесть прошли заранее заданные проверки. High и XHigh получили по 46/46 проверяемых критериев. Дополнительного выигрыша XHigh на этих задачах не обнаружено; сохраняем High по умолчанию и XHigh для сложных случаев.

| Задача | High | XHigh | Время High / XHigh, с |
|---|---:|---:|---:|
| BRIEF-03 | 18/18 | 18/18 | 25.53 / 35.15 |
| ANALYTICS-02 | 15/15 | 15/15 | 23.74 / 28.72 |
| CRM-07 | 13/13 | 13/13 | 15.29 / 15.91 |

BRIEF-03 проверял исправленные сроки, бюджет, ответственных, зависимости и ссылки на реплики. ANALYTICS-02 — пересчёт валют, общие знаменатели, взвешенный CPL, неполный период и отсутствие ложной причинности. CRM-07 — цитаты, отрицания, автоответ, условный интерес и запрет дальнейшего контакта.

Внутри каждой пары совпадают вход, JSON-схема и hash входа. Меняется только effort (`high` / `xhigh`); модель — `gpt-6.1-sol`, requested service tier — `default`. Пары выполнялись одновременно, поэтому время — наблюдение отдельных запусков, а не доказательство статистической скорости. Effective service tier не виден в событиях CLI. Usage сохранён как измерение токенов; из него не выводится расход подписки.

[Учебные входы и схемы](model-pilot/fixtures.json), [ответы, оценки и usage](model-pilot/results.json), [runner и фиксированные критерии](../scripts/run-model-pilot.mjs). Воспроизведение из репозитория:

```sh
codex login status
node scripts/run-model-pilot.mjs
```

Нужны Node.js 20+ и вход Codex через ChatGPT. Прогоны расходуют лимит подписки; API-ключи дочернему процессу не передаются. Результаты нового запуска сохраняются в отдельной временной папке, путь печатается в начале и конце; опубликованные результаты сохраняются. При необходимости второй аргумент задаёт папку результата. При непрохождении критериев runner завершится с ненулевым кодом. Входы учебные; инструменты, интернет и внешние действия для задач не требуются.

Серия не сравнивает Sol с Luna, Astra, Claude, Gemini или Grok. Один запуск каждой конфигурации на трёх учебных пакетах не доказывает общее превосходство и не заменяет [пилот на реальных материалах](pilot-plan.md). Стиль длинных ответов, поиск, медиа и интеграции этой серией не оценивались. Независимый проверяющий сверил эталоны, методику и все шесть ответов; существенных замечаний нет.
