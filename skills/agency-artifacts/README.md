# Agency Artifacts 0.2.0

Переносимый стандарт метаданных для MD/JSON документов агентства. Источник дистрибуции — эта папка agency-router; установка — копия в ~/.bb/skills/agency-artifacts после проверки локальных изменений. Не требует подключения к плагину Агентство.

Python 3.10+; зависимости requirements.txt рекомендуется ставить в отдельный venv. `python scripts/artifact.py validate FILE...` проверяет новые артефакты, `python scripts/artifact.py init FILE --format md --title TITLE --department content` создаёт только новый draft. `python scripts/test_artifact.py` — проверки схемы и форматов. `assets/metadata.schema.json` пригодна для будущей интеграции; примеры в assets/ не являются реальными клиентскими документами.

Исключения: raw, код, JSONL, закрытые внешние JSON-схемы и SKILL.md не переписываются; sidecar/родной manifest сохраняет контракт. Проверка не удостоверяет человека и не публикует документ. Откат установки: удалить только собственную установленную копию, сохранив исходники и артефакты. Новые файлы совместимы с обычными Markdown/JSON-инструментами, но потребителя front matter нужно проверить до миграции.

Редакция 0.2.0: выбор формата по таблице, внешняя задача без BB, точная обработка неизвестных привязок, версий, отсутствия Python и прав записи. Схема agency-artifact/1.0 и валидатор не изменены.
