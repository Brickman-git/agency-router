# Model Task Prompts 0.3.1

Переносимый навык подготовки и аудита поручений GPT-5.6, Astra, Claude, Gemini и Grok. Переносимая дистрибуция — эта папка репозитория agency-router. Установка: скопировать папку в пользовательский слой `~/.bb/skills/model-task-prompts`, сначала проверить отсутствие локальных изменений. Новая установка не меняет уже работающих исполнителей. Откат новой установки — убрать только эту папку; исходники и результаты задач сохраняются.

`SKILL.md` — вход, `references/` — краткие справки с официальными источниками и архитектура, `assets/task.example.json` — черновик, `scripts/prompt-kit.js` — общий компилятор для Node и страницы. Python и внешние пакеты не требуются; нужен Node.js.

```sh
node scripts/test.cjs
node scripts/test-project.cjs
node scripts/compile.cjs assets/task.example.json
node scripts/scaffold.cjs /existing/project seo-semantics-2026-09 SEO-01
```

Компилятор печатает промпт; scaffold создаёт минимальную задачу. Они не запускают модели, не проверяют права API и не публикуют материалы. Типы, режимы и инструменты проверяются по живому каталогу перед исполнением. Для обычного чата явный вызов навыка надёжнее автоматического: в пробе без имени навык не был прочитан. Источник документации проверен 2026-09-13; назначения моделей остаются гипотезами до измерения на заказах.

Версия 0.2 добавляет [структуру агентства](references/agency-project.md), `assets/project.example.json`, шаблоны дизайн-брифа и разбора конкурента, каталог процессов в `assets/agency-operating-model.json`. Отдел хранит канонический результат, work/tasks — контракт и историю исполнения со ссылками. `scripts/project-context.js` добавляет зависимости знаний, роли, условные навыки и gates. Проверки: базовый компилятор, граф зависимостей, источники, редакторский контракт и маршруты результата. Компилятор проверяет поля решения; достоверность решения человека и существование файлов проверяет исполнитель.

В 0.3: 80 конечных результатов в 16 группах, их короткие маршруты и 17 основных процессов; ссылки на 16 прочитанных источников с типом доказательства. Для статьи обязательны текст + visual-plan + краткие ТЗ; число 0…N и размещение — результат редакторского решения. Пример без изображений не создаёт дизайн-задание.
