# GPT Astra

Архив до 2026-09-30. Эта модель исключена из активных назначений. Для нового поручения см. [GPT‑6.1 Sol](gpt-6.1.md).

Проверено 2026-09-13. [Официальное руководство Astra](https://developers.openai.com/api/docs/guides/latest-model).

Из документации: Astra чувствительна к инструкциям навыков и AGENTS.md, склонна уточнять существенные неизвестные и тщательно проверять код. Задавать ожидаемую автономность, стиль, объём проверок и условия делегирования. Для небольшого исправления широкая регрессия может расходовать лишние ресурсы.

Локальная адаптация: результат и критерии важнее подробного ритуала действий. Продолжать уже разрешённую работу; спрашивать о неизвестном, действительно меняющем решение, после чтения доступного контекста. Проверки привязать к изменившемуся поведению. Для ограниченной задачи достаточно одного исполнителя; параллельных помощников разрешать только при независимых подзадачах и явной необходимости. Не добавлять разрешения поверх действующих правил среды.

Low — кандидат для короткого сложного решения или разбора противоречия после Terra/Sol; Medium/High — усиление при недостижении приёмки. Эти назначения требуют местной калибровки. Не считать frontier автоматически дороже за завершённый результат: учитывать повторные попытки и всю цепочку.
