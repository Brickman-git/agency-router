# GPT‑6.1 Sol

Обновлено 2026-09-30. [Модель и поддерживаемые режимы](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [настройки агентов Codex](https://learn.chatgpt.com/docs/agent-configuration/subagents).

Политика владельца библиотеки: `gpt-6.1-sol`, effort `high`; для трудных противоречий и сложных задач — `xhigh`. Requested serviceTier — `default`, обязательного Fast нет. Это стартовая конфигурация, а не измеренный результат сравнительного пилота. Luna, Astra и GPT‑5.6 Sol/Terra исключены из активных привязок.

Общий контракт сохраняется: цель, фактические входы, разрешённые действия, наблюдаемый результат и приёмка. Сохранять обязательные факты и ограничения; продолжать разрешённую работу, используя доступный контекст. Существенные неизвестные обозначать, отсутствующие данные не выдумывать. Проверки соразмерны изменению; для отдельного рецензента использовать свежий контекст даже при той же модели.

Модель и effort задаются настройками исполнителя, а не фразой в промпте. Поддерживаемые API effort: `low`, `medium`, `high`, `xhigh`, `max`; `none` и `minimal` не поддерживаются. Для API-вызовов с инструментами нужен Responses API; BB-конфигурация не является API-запросом. До запуска проверить фактическую доступность, инструменты и effective config. При недоступности модели сообщить конкретное ограничение либо выбрать подходящего исполнителя в пределах поручения.
