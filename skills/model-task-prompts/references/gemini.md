# Gemini

Архив до 2026-10-01. Это семейство исключено из активных назначений и компилятора. Для нового поручения см. [GPT‑6.1 Sol](gpt-6.1.md).

Проверено 2026-09-13. [Официальные стратегии промптинга](https://ai.google.dev/gemini-api/docs/prompting-strategies).

Из документации: прямые формулировки, единая структура разделителей, определения неоднозначных терминов; важные ограничения в начале/system, длинные данные перед конкретным вопросом. Ссылаться на изображения/аудио/видео как на отдельные входы. Явно определить объём и форму результата. Для Gemini 3.x не менять параметры сэмплирования без необходимости; руководство рекомендует значения по умолчанию. Расчёты выполнять доступным кодовым инструментом. Запрашивать выводы и доказательства; изложение внутреннего мышления обычно не требуется.

Локальная адаптация: проверка по рубрике получает материал, правило и формат «дефект → место → основание → исправление». Для извлечения — схема, ID и null для отсутствующего. Для исследований — актуальная дата из среды и ссылки на прочитанные источники. Не переносить указанную в примере документации дату отсечения знаний на любую версию Flash. Antigravity передаёт только фактически доступные инструменты и модальности; наличие Gemini не означает наличия Google Search grounding, генерации картинок или доступа к видео.
