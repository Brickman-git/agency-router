# GPT-5.6: Luna, Terra, Sol

Архив до 2026-09-30. Эта модель исключена из активных назначений. Для нового поручения см. [GPT‑6.1 Sol](gpt-6.1.md).

Проверено 2026-09-13. [Официальное руководство GPT-5.6](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.6).

Из документации: держать промпт компактным, каждое правило формулировать один раз; давать только относящиеся к задаче инструменты. Примеры сохранять, если они задают требование продукта или исправляют измеренную ошибку. Чётко определить полномочия и требуемое содержание ответа. Изменять промпт небольшими группами и сравнивать на одинаковых заданиях; внутренние результаты OpenAI не обещают тот же выигрыш здесь.

Локальная адаптация: общий контракт один для трёх моделей. Luna получает ограниченный пакет извлечения, нормализации или проверки; Terra — обычную инструментальную работу; Sol — зависимые решения и синтез. Это стартовые гипотезы роутера, не отдельные официальные правила для каждого имени. Не пытаться компенсировать отсутствующие данные огромной инструкцией. Сложность увеличивать по наблюдаемому провалу приёмки.

Настройки задаются отдельно. Ограничение владельца Luna High/Max Fast сохраняется всегда. Не менять API caching, reasoning context или pro mode по совету из текста, если используемый CLI их не предоставляет. Сохранить в коротком ответе доказательства, существенные ограничения и путь результата.
