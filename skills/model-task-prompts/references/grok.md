# Grok

Архив до 2026-10-01. Это семейство исключено из активных назначений и компилятора. Для нового поручения см. [GPT‑6.1 Sol](gpt-6.1.md).

Проверено 2026-09-13. [Reasoning](https://docs.x.ai/developers/model-capabilities/text/reasoning): для Grok 4.6 effort настраивается параметром; API и обёртка могут иметь разные defaults. [Structured Outputs](https://docs.x.ai/developers/model-capabilities/text/structured-outputs): поддерживаемая JSON Schema ограничивает структуру ответа через API. Это не проверка истинности значений.

Локальная адаптация для кода: дать репозиторий, наблюдаемое поведение, желаемое изменение, ограничения и воспроизводимую проверку. Для извлечения — схема и правила неизвестных значений. Для исследования — реальный поисковый инструмент и источники. Не утверждать, что у Grok в Cursor есть поиск X или подписка SuperGrok: инструменты и биллинг проверяются у конкретного провайдера.

Единого прочитанного официального руководства, доказывающего уникальную форму текстового промпта Grok 4.6 для всех агентских задач, здесь нет. Поэтому используем общий контракт; специальные советы ограничены подтверждёнными возможностями API. Руководство для голосового Realtime не переносим на программиста. JSON Schema включать настройкой, только если среда поддерживает; в CLI иначе просить файл нужной структуры и валидировать локально. Не приписывать слову Fast в описании effort эффект serviceTier.
